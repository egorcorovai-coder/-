# Cursor Position — Minecraft Java 1.21.4 (Fabric)

Клиентский мод: выберите место появления курсора при открытии инвентаря, сундука и других контейнеров. При закрытии инвентаря игра захватывает и скрывает курсор для управления камерой; мод запоминает его позицию перед этим.

## Скачать готовый мод

[Скачать cursor-position-1.21.4.jar](https://github.com/egorcorovai-coder/-/raw/refs/heads/main/downloads/cursor-position-1.21.4.jar)

Положите JAR в `.minecraft/mods` и запустите Minecraft 1.21.4 с Fabric Loader. Сборка проверена; поведение внутри игры пока не проверялось.

## Управление

- **F8** — настройки (в игре или в инвентаре).
- **Выбрать точку на экране** — затем кликните в нужном месте. Esc отменяет выбор.
- **Последняя позиция** — возвращает курсор туда, где он был при последнем закрытии контейнера (в пределах текущего запуска игры).
- **По центру** — сброс на центр экрана.

Выбранная точка сохраняется между запусками в `config/cursorposition.json`, в долях размера окна. Fabric API не требуется. На сервер мод устанавливать не нужно.

## Сборка и установка

Нужны Java 21 и доступ к Maven Fabric и серверам загрузки Minecraft.

```sh
./gradlew build
```

На Windows: `gradlew.bat build`.
Готовый мод: `build/libs/cursor-position-1.0.2.jar` (не `-sources.jar`). Установите Fabric Loader для **1.21.4**, положите JAR в `.minecraft/mods` и запустите профиль Fabric.

## Проверка в игре

```sh
./gradlew runClient
```

Откройте мир, нажмите F8 и выберите точку. Откройте/закройте инвентарь клавишами E и Esc; проверьте также сундук. В режиме последней позиции переместите курсор, закройте и вновь откройте контейнер. Проверьте изменение размера окна и перезапуск игры для сохранённой точки. Управление камерой после закрытия должно оставаться обычным.

## Исправление 1.0.2

При открытии контейнера координаты Minecraft сразу синхронизируются с видимым курсором: подсветка и нажатие используют выбранную позицию без ручного движения мыши.

Версия 1.0.2: однократное движение на 1 пиксель после открытия и синхронизация с GLFW перед обработкой мыши. Версия отображается в меню F8. Проверена сборка; проверка в игровом клиенте ещё требуется.

## Меню выбора слота — 1.0.3

В мире нажмите F8 → «Выбрать слот в инвентаре», затем нажмите на слот своего инвентаря. Выбор сохраняется сразу; Esc возвращает без нового выбора. Зелёная рамка показывает выбранный слот. Предметы в меню не перемещаются. Курсор привязан к центру слота, а не к абсолютной точке окна. В сундуках выбирается тот же слот вашего инвентаря, если он присутствует. При отсутствии слота используется сохранённая точка экрана.

Замените старый JAR на `cursor-position-1.21.4-v1.0.3.jar`. Версия видна в заголовке F8. Сборка проверена, интерактивная проверка в Minecraft пока не выполнена.
